# Heritage Market – Traditional Arab Products E‑commerce

**Heritage Market** is a fully responsive, bilingual‑ready (RTL) website showcasing authentic Arab heritage products. The project combines traditional aesthetics with modern front‑end technologies and serves as an academic demonstration of HTML, CSS, JavaScript, JSON, and RESTful API integration.

## 📖 Overview

Heritage Market is an online marketplace dedicated to traditional Arab handicrafts, textiles, pottery, perfumes, and more. The site is built with a strong focus on:

- **Full Arabic content** (RTL layout, Arabic UI text)
- **Dark / Light mode** toggle
- **Product catalog** loaded from `products.json` (12 items)
- **Promotions & customer reviews** fetched from `db.json` via AJAX (GET / POST)
- **Favorites list** stored in `localStorage`
- **Interactive contact form** with Arabic validation messages
- **Responsive navigation** with mobile menu
- **Smooth scroll‑to‑top** button
- **Animated elements** on scroll
